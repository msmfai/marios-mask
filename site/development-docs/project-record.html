Project record

Purpose: give the size of the project and the share of AI work, and state what each number can and cannot show. Counted on 2026-11-12.

Summary

The project ran from 2026-06-12 to the present, about five months. The private repository has more than 8,000 commits. Claude is named as co-author on 2,381 of them. Codex worked in at least 969 sessions. These numbers show the scale. They do not give an exact share of AI work, for the reasons in the table.

Author names

Each worktree sets its own Git author name. One placeholder name is on 6,558 commits. Thus the author name does not show whether a person or an agent wrote a commit.

Division of work

  • Most code, tests and technical documents were written by AI coding agents: Anthropic's Claude Code and OpenAI's Codex.
  • The owner set the architecture, made the design and creative decisions, tested the builds by playing them, and decided each release (document 3).
  • The game uses the community decompilations of Majora's Mask and Super Mario 64. It contains no Nintendo assets. Players supply their own ROMs (document 13).
