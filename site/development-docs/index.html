Mario's Mask builder

Development docs

Reference for the development patterns used to build Mario's Mask with AI coding agents.

Purpose

Mario's Mask is a mod of the Nintendo 64 game The Legend of Zelda: Majora's Mask. It adds Mario as a playable form, with the movement code of Super Mario 64.

AI coding agents wrote most of the code. These documents record the patterns that made that work: how the agents were directed, how their output was verified, and which failures occurred.

The documents are written for developers who use coding agents on large, low-level projects such as ROM mods.

Authorship

Marin Moran conceived and directed Mario's Mask: they set its architecture, made every design and creative decision, playtested each build on emulator and real Nintendo 64 hardware, and decided every release. Most of the code and documentation was written by AI coding agents (Anthropic's Claude Code and OpenAI's Codex) under the author's direction and review, and the author takes full responsibility for the result. The game is built on the community decompilations of Majora's Mask and Super Mario 64. It contains no Nintendo assets: players supply their own ROMs.
