Mario's Mask builder

Development docs

Reference for the development process used to build Mario's Mask with AI coding agents.

Purpose

Mario's Mask is a mod of the Nintendo 64 game The Legend of Zelda: Majora's Mask. It adds Mario as a playable form, with the movement code of Super Mario 64.

AI coding agents wrote most of the code. One person directed the agents, made the design decisions, and tested the game. These documents record the process: how work was divided, how agents were directed, how their output was verified, and which failures occurred.

The documents are written for developers who use coding agents on large, low-level projects such as ROM mods. A reader who follows them, with the three original ROMs, a computer and coding agents, can repeat the process.

How to read these documents

  • Start with document 1. It shows the full process in one figure and links to the other documents.
  • Documents 2 to 5 describe how the agents were directed and corrected. These parts apply to other projects.
  • Documents 6 to 11 describe the technical methods for this mod.
  • Documents 12 to 14 describe the setup, the release process and the project record.

Authorship

Marin Moran conceived and directed Mario's Mask: they set its architecture, made every design and creative decision, playtested each build on emulator and real Nintendo 64 hardware, and decided every release. Most of the code and documentation was written by AI coding agents (Anthropic's Claude Code and OpenAI's Codex) under the author's direction and review, and the author takes full responsibility for the result. The game is built on the community decompilations of Majora's Mask and Super Mario 64. It contains no Nintendo assets: players supply their own ROMs.
