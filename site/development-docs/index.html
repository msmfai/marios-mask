Mario's Mask builder

Development docs

Reference for the development process used to build Mario's Mask with AI coding agents.

Purpose

Mario's Mask is a mod of the Nintendo 64 game The Legend of Zelda: Majora's Mask. It adds Mario as a playable form, with the movement code of Super Mario 64.

AI coding agents wrote most of the code. One person directed them. These pages describe the working model and the verification loop that made this possible. They are for developers who use coding agents on large projects where errors are hard to see.

The idea in one paragraph

The person decides what to build. Agents build it. Nothing an agent says counts as evidence: a change is accepted only when the game itself shows the right result, measured against the original game as the reference. Each fault, from a test or from play, leaves a new check behind, so the same mistake is not made twice. Most of the effort goes into that loop, and the rest of the process follows from it.

Authorship

Marin Moran conceived and directed Mario's Mask: they set its architecture, made every design and creative decision, playtested each build on emulator and real Nintendo 64 hardware, and decided every release. Most of the code and documentation was written by AI coding agents (Anthropic's Claude Code and OpenAI's Codex) under the author's direction and review, and the author takes full responsibility for the result. The game is built on the community decompilations of Majora's Mask and Super Mario 64. It contains no Nintendo assets: players supply their own ROMs.
