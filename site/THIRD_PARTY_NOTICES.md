# Third-party assets

## N64 Game Control

`n64-controller.svg` is the “N64 Game Control” vector distributed by SVG Repo
under the CC0 1.0 Universal Public Domain Dedication.

Source: https://www.svgrepo.com/svg/84805/n64-game-control

The bundled copy changes only its presentation colour and removes fixed
intrinsic dimensions so that it scales with the page.
