# Mario's Mask

Play *Majora's Mask* as Mario, with his movement, attacks, voice, animations,
items, and interactions adapted from *Super Mario 64*.

![Mario carrying a bomb in Termina Field](https://github.com/msmfai/marios-mask/releases/download/v0.1.0-alpha.7/selected-mario-bomb-jump.png)

## Build the game

1. [Download the builder for Windows, macOS, or Linux](https://github.com/msmfai/marios-mask/releases/latest).
2. Extract it and open **MariosMaskBuilder**.
3. Choose your USA Nintendo 64 game files for *Super Mario 64* and *Majora's Mask*.
4. Choose where to save the new game and click **Build Mario's Mask**.
5. Open `Marios-Mask.z64` in an N64 emulator or flash cart.

Raw `.z64`, `.v64`, and `.n64` files work, as do `.zip` and `.gz` archives.
Use game files you are legally entitled to use.

Find the stone Peach in Clock Town's Laundry Pool and play the Song of Healing
nearby to receive the Brother's Mask. Put it on to become Mario.

With fresh save data, File 1 starts as `Link` on Day 1 after the tutorial. File 2
begins a new game.

This is an early alpha. Back up your saves and
[report bugs](https://github.com/msmfai/marios-mask/issues/new/choose) without
uploading either game file.

The builder is free software under [GPL-3.0](LICENSE). It contains no playable
game and only builds locally from the two files you select. Its transparent
two-input recipe is [documented here](patcher/recipe/FORMAT.md).
